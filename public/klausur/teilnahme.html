Prüfung

Code und PIN stehen auf dem Zettel, den du bekommen hast.

Der Code gilt einmal. Wer die Seite schließt, kommt nicht von selbst wieder herein – dann hilft nur die Lehrkraft.

Was gespeichert wird

Kein Name, keine Klasse, keine Schule – es gibt kein Feld dafür. Gespeichert werden nur dein Code und deine Antworten, und die Antworten sind dabei so verschlüsselt, dass ausschließlich deine Lehrkraft sie öffnen kann. Wer die Zuordnung von Code zu Name hat, weiß nur sie; diese Seite kennt sie nicht.

So wird gekreuzt: Bei jeder Aufgabe steht, wie viele Antworten stimmen. Mehr geht nicht – wenn du so viele angekreuzt hast, musst du erst eines wieder abwählen.

Nach dem Abgeben lässt sich nichts mehr ändern.

Abgegeben

Deine Antworten sind angekommen. Du kannst die Seite jetzt schließen.

Ein Ergebnis steht hier nicht – diese Seite kennt die richtigen Antworten nicht. Die Auswertung macht deine Lehrkraft.
